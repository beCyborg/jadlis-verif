# jadlis-verif

Мысль: план рвут три модели порознь, арбитр сводит находки в один список, по каждой ты говоришь «принять / отклонить / переписать», и только принятое уходит в правки.

## mindmap

Центральный узел: `verif`

- **Проверяющие**: три модели, порознь, ответы не видны, рамка у каждой своя
- **Что ищут**: дыры, а не опечатки; порядок шагов; пропущенный этап; чего в плане нет
- **Сведение**: один список, дубли убраны, совпавшее выше, одиночное отдельно
- **Выход**: интервью по каждой находке, принять, отклонить, переписать, правки в плане
