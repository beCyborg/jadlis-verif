# Твой план проверяет тот, кто его написал, — и та же модель, которая его писала

Две модели разных компаний рвут его порознь, не видя ответов друг друга, а арбитр сводит находки
в один список — до того, как ты в план вложился.

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-verif@jadlis
```

Ключи не нужны — это единственный в линии, кому не нужны Brave и Firecrawl. Нужна своя
подписка ChatGPT — под Codex CLI.

![Колонки замечаний от моделей-проверяющих и сведённый арбитром общий список находок](docs/img/hero-jadlis-verif.webp)

Текстом: отдельные разборы одного плана слева и общий список арбитра справа, где у каждой
находки стоит развилка «принять / отклонить / переписать».

Это моё рабочее место, выложенное как есть, а не продукт: чем перестал пользоваться — убрал.

## Как это работает

![Один план уходит моделям-проверяющим порознь, арбитр сводит находки, ты отвечаешь по каждой, потом правки](docs/img/how-jadlis-verif.webp)

На входе — твой план одним файлом.
Внутри — Codex и Fable разбирают его параллельно и не видят ответов друг друга; арбитр
сводит находки в один список и поднимает то, на чём разборы сошлись.
На выходе — разбор находок: принять, отклонить или переписать, и только принятое уходит в правки.
Разбор идёт как выберешь: **авто** — плагин применяет решения арбитра сам и спрашивает только по
сильным развилкам, не больше четырёх вопросов; **вручную** — по вопросу на каждую находку.

Текстом: план → два разбора порознь → арбитр сводит в один список → ты выбираешь «авто» или
«вручную» → правки в плане.

### Чем отличается от Perplexity и ChatGPT Deep Research

Сравнение только по механизмам — не по тому, кому верить.

| Механизм | Этот плагин | Perplexity | ChatGPT Deep Research |
|---|---|---|---|
| Разбирают ли текст несколько моделей порознь, не видя ответов друг друга | да, две модели разных компаний | да, в режиме Model Council: три модели параллельно | в документации не нашёл |
| Сводятся ли расхождения между разборами в один список | да, арбитром | да, отдельная модель-синтезатор в Model Council | в документации не нашёл |
| Помечается ли спорное отдельно от совпавшего | да, совпавшее и одиночное разведены | да, показано, где модели сошлись и где разошлись | в документации не нашёл |
| Остаётся ли список находок с твоим решением по каждой | да, после батч-интервью | частично: находки по ходу, решения по ним нет | частично: правится план до запуска, не находки |
| Проверяются ли первоисточники в вебе | включается, если установлен `jadlis-search` | да | да |

Столбец плагина проверен 07.09.2026. Чужие столбцы собраны в тот же день по официальной
документации: [Model Council](https://www.perplexity.ai/hub/blog/introducing-model-council) и
[справка Perplexity](https://www.perplexity.ai/help-center/en/articles/13600190-what-s-new-in-advanced-deep-research),
[справка OpenAI по Deep Research](https://help.openai.com/en/articles/10500283-deep-research-faq).
«В документации не нашёл» значит ровно это, а не «нет». Первые три строки Perplexity — про
режим Model Council, не про Deep Research: сам по себе он многомодельного разбора с арбитром не
заявляет.

### Пример

У тебя план ремонта: порядок работ, что делаешь сам, на чём экономишь, когда въезжаешь. Две
модели читают его порознь. Codex цепляется к порядку работ: стяжка и её сушка стоят раньше, чем
предполагает доставка. Fable находит другое: приёмки после этапа в плане нет вообще, переделка
вскроется в конце, — и спрашивает про то, чего в плане нет вовсе: что происходит, если мастер
пропадает на неделю. Арбитр сводит это в один список и показывает, где оба сошлись на одном и
том же. Ты идёшь по списку и по каждой находке говоришь: принять, отклонить, переписать. В план
уезжает только принятое — до того, как приехали материалы.

## Установка и первый запуск

**а) Текст для вставки агенту.** Скопируй целиком в чат Claude Code:

```
Ты — установщик. Поставь на этот Mac плагин jadlis-verif из маркетплейса jadlis.
Сначала проверь, что стоит Claude Code и подписка активна, и что на машине есть Codex CLI.
Скажи мне «есть» или «нет» по каждому — токены и содержимое конфигов не печатай.
Нет Codex CLI — остановись и скажи мне: без него это не работает.
Дальше выполни ровно эти команды, дословно, ничего не сокращая:
1. claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
2. claude plugin install jadlis-verif@jadlis
3. claude plugin list — покажи мне строку про jadlis-verif и его версию.
Ключи API у меня не спрашивай: этому плагину они не нужны, и в конфиги ключей ничего не пиши.
Перед каждой командой покажи её мне целиком и дождись «да». Сказал «нет» — не выполняй.
Команда вернула ошибку — остановись, покажи вывод, к следующей не переходи.
```

**б) Команды руками.**

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-verif@jadlis
claude plugin list
```

Первая команда ничего не ставит — она добавляет маркетплейс. Ставит только вторая, и снимается
она одной строкой: `claude plugin uninstall jadlis-verif@jadlis --keep-data`.

**в) Короткая команда.** Открой Claude Code в папке, где лежит план, и набери:

```
/verif <путь к файлу с планом>
```

Не находится — сверь имя строкой `claude plugin list`. Первый разбор запускай на плане, в который ты ещё не вложился: смысл в том, чтобы
дыра вскрылась до денег, а не после.

## Границы, стоимость, обновление

**Чего не делает.** Не пишет план за тебя — только рвёт написанный. Не принимает решения по
находкам: принять, отклонить или переписать говоришь ты, и в правки уходит только принятое.
Не проверяет первоисточники в вебе сам по себе: веб-проверка включается дополнительно, если у
тебя установлен `jadlis-search`. И главное: совпадение двух разборов — это совпадение двух разборов, а
не доказательство. Арбитр показывает, где оба сошлись, а где остался один голос против другого;
решение всё равно твоё.

**Что нужно.** Ключи не нужны — это единственный в линии, кому не нужны Brave и Firecrawl. Нужна
одна своя подписка: ChatGPT — под Codex CLI. Проверено на Codex CLI 0.153.4 (07.09.2026); ниже
этой версии не проверял.

**Порядок расхода токенов.** Тяжёлый прогон — десятки субагентов из твоей квоты; несколько
прогонов подряд в одно окно не помещаются. Часть работы уходит в твою подписку ChatGPT,
часть — в квоту Claude Code. Планируй разбор как отдельную задачу на сессию, а не как быстрый
вопрос между делом. Во что это обходится в деньгах — не мерил и цифру не назову.

**Проверено там, где я работаю:** мой Mac, мои подписки. На чужих машинах не проверял — если
у тебя не встало, напиши в issue репозитория.

**Условия использования.** Лицензии нет: все права сохранены за автором. Читать и
пользоваться лично можно. Коммерческое использование, переиздание и включение в свои
продукты — по договорённости со мной.

**Обновление.** У стороннего маркетплейса авто-обновление на твоей стороне выключено: пока не
запустишь первую команду, у тебя остаётся та версия, которую ты поставил.

```
claude plugin marketplace update jadlis
claude plugin update jadlis-verif@jadlis
claude plugin list
```

Переустановка, если что-то встало криво:

```
claude plugin uninstall jadlis-verif@jadlis --keep-data && claude plugin install jadlis-verif@jadlis
```
